# Kam Ephrem portfolio

This is a local React portfolio built with esbuild. Node.js 20 or later is recommended.

```sh
npm install
npm run dev
```

Open `http://127.0.0.1:4173` in a browser. The development server watches the React and CSS files; stop it with Ctrl+C. Run `npm run build` to generate the production site in `dist/`.

The public project description is based on the linked repository's README; its features were not independently tested. Review current roles, credentials, and project details with the owner before publishing.
